# Base de données

L'espace membre partage la base Supabase d'Anthony Sirius avec la page de vente et le
CRM des setters. Tout le schéma (leads, CRM, espace membre) s'installe en une
fois avec un seul fichier :

    CRM Sirius/supabase/INSTALLATION.sql

À coller dans Supabase → SQL Editor → Run. Rejouable.
